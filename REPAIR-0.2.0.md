## Activation and limits

Restart Desktop, create a fresh session and select JEV Decision. Older processes can retain old ES modules and existing sessions keep their preset.

The upgrade changes static text once, requiring a new prefix to warm. Subsequent notices/counters append after retained history and tools are never dynamically pruned or reordered. Provider caching is best effort and no fixed 99.8% hit rate is promised.

One bounded JEV call per new human request is an explicit cost. End-to-end speed and accuracy improvements need repeated same-task A/B measurement and are not claimed here. Existing historical ledgers are not deleted. The classifier supplements host permissions; lexical checks cannot cover arbitrary dynamic shell commands or symlinks.
