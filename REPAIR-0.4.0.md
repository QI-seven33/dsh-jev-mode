# 0.4.0 deterministic-first desktop adaptation

- Explicit bounded manifest/README queries use deterministic selection with no decision HTTP request, including when the JEV budget is zero.
- Only short eligible single-read contrasts with both available candidates enter optional semantic selection. Compound reads, writes, Shell/Git work and unrelated tasks retain ordinary planning.
- Failed or low-confidence semantic selection falls back to planning; it grants no execution permission.
- Risk classification scope and authorization cuts are retained. Fail-open configuration migrates to escalation; JEV never replaces downstream permission vetoes.
- The focused static protocol removes automatic advisory decision prompting. Full/compact legacy protocols remain explicitly selectable for compatibility.
- Native notices identify code/jev selection; jev_status exposes version, attempt/fallback/reuse counters and selector wait. Status runtime context is disabled by default.
- Native read visibility, bounded regular-file checks, before/after identity, evidence reuse invalidation and V4 producer-owned source kind remain enforced.

The earlier selector experiment motivated this change; it did not evaluate this hybrid as a fourth arm. Scripted tests establish control flow, not real model quality. A live smoke test is not a calibrated safety benchmark. See ACCEPTANCE.zh.md and RELEASING.md.
